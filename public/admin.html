打卡範圍設定

瀏覽器基於安全限制無法讀取裝置連接的 WiFi SSID/BSSID，因此以「員工連上公司 WiFi 後對外的公用 IP（或內網閘道 IP）」 作為近似驗證方式。此 IP 通常固定，可請 IT 提供公司網路的對外 IP 並填入此處。若需要更嚴謹的 SSID/BSSID 驗證，需改用原生 App 並透過作業系統的 WiFi 資訊 API 取得（詳見 README）。

匯出打卡記錄到 Google Sheet

管理者補登打卡紀錄

直接為員工新增一筆打卡紀錄（例如員工忘記帶手機、裝置故障無法自行補登等情況）。 新增後狀態自動為「已確認」，不需要員工另外送出忘記打卡申請或管理者審核。

打卡記錄管理

可直接修正重複打卡、打錯類型或打錯時間的紀錄，避免匯出/薪資試算的結果與實際情況不符。 「時間」欄位以台北時間顯示與輸入。修改或刪除後請視需要重新匯出到 Google Sheet。
